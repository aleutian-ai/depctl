# Real-world geospatial datasets: Census TIGER/Line 2025 (Northeast +
# California), NOAA nautical charts and maritime boundaries (West
# Coast). One line per source: "<category> <url>". category becomes a
# subdirectory of -root; the downloaded zip's basename (extension
# stripped) becomes the extraction directory name there.
#
# Deliberately NOT included: NOAA BlueTopo bathymetry — it's an S3-hosted,
# tile-based dataset (s3://noaa-ocs-nationalbathymetry-pds/) too large to
# blindly bulk-sync; list the bucket with the AWS CLI to pick specific
# CA/OR/WA tiles instead: `aws s3 ls --no-sign-request s3://noaa-ocs-nationalbathymetry-pds/BlueTopo/`
#
# Run with: go run ./hack/fetch-geodata [-root DIR] [-concurrency N]

# TIGER/Line 2025 — technical documentation (schema/field reference,
# not raw geometry — the kind of "metadata about the dataset" that's
